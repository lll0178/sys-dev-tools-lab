## 1. Issue（重写）

- **标题**：`sdt-greet` 对空白 `--name` 未拒绝，仍输出问候语
- **环境**：Linux/WSL，Python 3.14，wheel 安装的 greetlab-25030021043；Windows 上是否复现：待确认
- **复现命令**：`sdt-greet --name " "`
- **期望结果**：拒绝空白姓名，以非零退出码结束
- **实际结果**：输出 `Hello, !`，退出码 0

## 2. 提交信息（重写）

**标题**：Reject blank --name in greetlab CLI

**正文**：传入纯空白字符串时程序仍打印问候语并以 0 退出，会掩盖调用方的参数错误。在 main 中对 `a.name` 做 strip 校验，空白时调用 `parser.error` 以 SystemExit(2) 拒绝，并补充参数化回归测试。

## 3. 评审意见（重写）
